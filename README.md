# Pixelpart for GameMaker

This repository contains the official Pixelpart plugin for GameMaker 2024+. The plugin allows you to play Pixelpart effects directly within the GameMaker engine.

## Installation

Download the plugin from [pixelpart.net](https://pixelpart.net/plugins/). In GameMaker, open the project where you want to use Pixelpart, go to *Tools > Import Local Package* in the top menu and select the *pixelpart.yymps* package you just downloaded. Then import all files.

## Usage

A detailed user guide can be found on the [Pixelpart website](https://pixelpart.net/documentation/gamemaker/).

## Supported Platforms

The plugin supports the following target platforms:

- Windows
- Linux
- macOS
- Android

At the moment, iOS, console and HTML5 targets are not supported.
