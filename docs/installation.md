# Installation

You can install the Pixelpart plugin in your GameMaker project in the following way:

1. Download the plugin package *pixelpart.yymps* from the Pixelpart website.
2. In GameMaker, go to *Tools* and *Import Local Package* in the top menu.
3. Then, select the *pixelpart.yymps* package and import all files.

## Requirements

GameMaker 2024 or higher is required to use the Pixelpart plugin.

## Supported target platforms

The plugin supports the following target platforms:

Target   | Architectures      | Supported
-------- | ------------------ | ---------
Windows  | x86_64             | Yes
Linux    | x86_64             | Yes
macOS    | arm64, x86_64      | Yes
iOS      |                    | No
Android  | arm, arm64, x86_64 | Yes
HTML5    |                    | No
GX.games |                    | No
Console  |                    | No
