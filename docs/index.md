# Getting Started {#mainpage}

This is the documentation of the Pixelpart plugin for the GameMaker engine. Start by [installing the plugin](./installation.md) and [use Pixelpart effects](./usage.md) in your game. The plugin also offers an extensive [scripting API](./scripting.md) to access effects with *GML*.

## Requirements

GameMaker 2024 or higher is required to use the Pixelpart plugin.

## Platform support

The plugin supports the following target platforms:

Target   | Architectures      | Supported
-------- | ------------------ | ---------
Windows  | x86_64             | Yes
Linux    | x86_64             | Yes
macOS    | arm64, x86_64      | Yes
iOS      |                    | No
Android  | arm, arm64, x86_64 | Yes
HTML5    | wasm               | Yes
GX.games |                    | No
Console  |                    | No

## Feature support

The plugin supports the following features:

Feature | Supported
------- | ---------
2D effects | Yes
3D effects | No
Inputs | Yes
Triggers | Yes
Events | Yes
Custom materials | No
